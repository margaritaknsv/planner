# Мой планировщик

Личный планировщик: неделя и месяц, задачи с цветными тегами, события из Google Календаря.

- `planner.html` — исходник страницы (его же можно опубликовать в Claude).
- `build.py` — собирает сайт для GitHub Pages в папку `docs/`.
- `config.json` — OAuth Client ID Google для входа на сайте.

После правок в `planner.html` или `config.json`:

```bash
python3 build.py
git add -A && git commit -m "Обновить планировщик" && git push
```

На сайте задачи хранятся в скрытой папке приложения на вашем Google Диске и синхронизируются между устройствами после входа через Google.
